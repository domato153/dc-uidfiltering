# Research selection and transfer contract

Use `verification/research-selection.json` for the explicit signal/tier vocabulary. Its verifier tests declared signal combinations, not natural-language model triggering. A user request to search always triggers external research; never downgrade it because local evidence seems sufficient.

- ER0: exact repository source, current artifact, or existing independent evidence settles a repository-owned fact. Record the local basis; do not browse merely to repeat it.
- ER1: check the current primary authority for a changing API, standard, compatibility rule, or version-dependent detail that could alter a consequential choice.
- ER2: compare primary research, standards, official methods, or original case reports for competing solutions, a novel failure, a generalized claim, an internal evidence gap, test-plan precedent, or explicit research request. Include a plausible disconfirming method or limitation.
- ER3: when conflicting external evidence and high consequence coexist, deepen the review and retain the unresolved conflict as a defeater. This tier never manufactures certainty or grants permission for a wider change.

Before adaptation, state the external proposition and why current repository evidence cannot settle it. Appraise source authority, date/version, study or case context, relevant failure mechanism, and transferability to DCUF's userscript/host constraints. Test the adapted rule locally against a baseline, negative control, or counterexample. Do not count multiple reports using the same underlying data/oracle as independent corroboration.

For a consequential method decision, add or supersede a compact entry in `docs/work/DECISION_RATIONALE.md` with `SELECTED`, `NOT ADOPTED`, `DEFERRED`, reason, evidence, and revisit trigger. These are decision meanings, not PASS statuses; bind actual validation separately to receipts and exact artifacts. Summarize only durable reusable causes in maintenance notes. Do not copy `anima` or `translation` project-specific permission/event-log machinery into DCUF without a demonstrated missing control.
