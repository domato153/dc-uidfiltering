# 모바일 3.5.7

- 갤러리 목록과 글 본문에서 페이지 안에 세로 스크롤이 하나 더 생겨 스크롤이 끊기거나 하단 빈 공간으로 이어지는 문제를 수정했습니다.
- 목록 중간에서 위로 스크롤하면 전체글·개념글·글쓰기 줄이 다시 나타납니다. 상단으로 돌아오면 원래 위치에 복귀해 검색과 최근 방문을 가리지 않습니다.
- 새로고침 때 목록 상단 컨트롤이 준비될 시간을 잠시 확보합니다. 로딩이 길어지면 준비된 목록부터 표시합니다.
- 휴대폰 데스크톱 모드에서 게시글 제목과 말머리·댓글 수를 키웠습니다. 넓은 화면에서도 목록 제목을 더 읽기 쉽게 조정했습니다.

모바일 설치 파일은 **Dc_UserFilter_Mobile_v3.5.7.user.js**입니다. PC는 기존 **2.0.0** 파일을 함께 제공합니다. **SHA256SUMS.txt**로 파일을 검증할 수 있습니다.
