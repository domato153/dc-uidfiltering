## Enforced at the existing boundary

NEXT's existing dependency mechanism freezes `selected-design-image`; one `Design reference region` line names the affected part. Both the preparation helper and the existing comparator read that selection. Design comparisons require `designReference: {path, sha256, decisionPath, region}` and a short `visualRequirements` list for the changed claims. The authority document must bind the image hash; path/hash/region must agree with NEXT. A matching-size secondary proposal is still permitted, but cannot replace this selected design basis. Capture alone needs no new reference declaration.

Each changed requirement records `implementation` present/missing and `verification` passed/unverified/failed. A known missing effect must remain failed; passed requires hash-bound rendered evidence. Existing image-bound manual assessment remains necessary. This validates declarations/evidence identity, not human perception; false statements still require source/render review. Regression-only pixel comparisons cannot carry a design assessment. Historical manifests without the new fields fail closed on rerun until their actual basis is supplied; immutable historical receipts are not rewritten.

Preparation returns explicit `requirementsStatus`; its legacy `reviewed` flag only means an assessment was supplied. The comparator owns the final reference-fidelity result. Known missing work returns failure even when native pixel comparison is PIXEL_MATCH.

Passed evidence must be a hash-bound current PNG in a declared comparison case. This reuses the existing Playwright decoder rather than trusting a functional log, unused image or adding another image validator.

The native Playwright report also attaches the exact selected original to every comparison. Thus a secondary matching-size proposal cannot make the original disappear from the report; the selected original remains the authority above expected/current/diff. The local viewer opens the original B1 writer region first.

Cost: a few local files/hashes per design comparison, no daemon/network/model call and no new product test on an unchanged runtime. Reuse normal light/dark and one relevant backing probe; do not repeat the whole checklist or invent a beauty score. Final reports keep functional result, reference/material fidelity and user preference separate.

`inspect-continuity` now exposes the selected image's actual/expected hash and region directly. Both consumers compare that active frozen dependency and region, so a stale resume or a newly substituted HTML proposal is rejected at the comparison boundary. This does not prove that an agent actually looked at or understood the image; original-region viewing and rendered inspection remain explicit.
